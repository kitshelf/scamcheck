# my-files — your private space

This folder holds the messages you paste and the reports ScamCheck returns. It is git-ignored in full: a fresh clone protects it the moment you drop a file in.

What lands here, if you choose to save it:

- `YYYY-MM-DD-scamcheck-report.md` — a saved screen of one message.
- The redacted message text, if you keep it alongside the report.

Rules that hold for this folder:

- Never commit, push, or transmit anything here.
- Run the redaction pass before pasting; strip your name, phone, address, and account digits.
- A saved report is a note to yourself, not evidence. The kit never files anything on your behalf.
