# results/ — recorded runs

Dated records of real runs of the fixture gauntlet, one folder per fixture:

`results/<fixture-id>/<YYYY-MM-DD>-<model>-screen.md`

Each file holds the full report the run produced plus the self-assessment (format in [`../README.md`](../README.md)). These are kit evidence — they are committed.

The adversarial release gate also lands here as a dated report, for example `2026-11-20-adversarial-release-gate.md`.

A real user's screen never lands here. User output goes to the kit's `my-files/` and is never committed, pushed, or transmitted.
