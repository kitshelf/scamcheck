# The screen

The kit's one workflow: reads a suspicious message the way a careful friend with a scam-pattern library would — markers quoted from the message's own words, a fixed-label reading with the count, verify steps that end in the user's own facts, and the safe next action. Jobs is the shipped family; rentals, banking, marketplace, and romance ship in later versions (`../shared/families.md`).

Who it is for: anyone about to reply to a too-good message from a stranger.

## Files

| Path | What it is |
|---|---|
| `SPINE.md` | the compiled kit, one paste — the quick start's entire payload |
| `START.md` | the chat-user front desk (the two-paste flow) |
| `00-principles.md` | this workflow's constitution |
| `01-screen/screen.md` | the full workflow: steps, output template, self-check |
| `rubrics/markers-jobs.md` | the 17-marker jobs library with calibration lines + the verify checklist |
| `examples/` | pointers to the worked examples (the catch and the not-catch) |

Also uses: `../shared/labels.md`, `../shared/families.md`, `../shared/redaction.md`, `../shared/recovery.md` (branch), `../shared/local-models.md` (offline runs).

## How to use

- **In any AI chat:** paste `SPINE.md`, then your redacted message. Two pastes, about ninety seconds.
- **With an AI agent that reads files:** say "screen this message", the agent follows `AGENTS.md`.
