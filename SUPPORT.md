# Support

ScamCheck is a Markdown kit. There is nothing to install and no service to keep running.

## Where to ask

| You want to | Go to |
|---|---|
| Report a security problem, including an injection-defense bypass | [`SECURITY.md`](SECURITY.md) — private reporting, never a public issue |
| Suggest a marker the kit misses | [Open a marker-submission issue](https://github.com/kitshelf/scamcheck/issues/new?template=marker-submission.md) |
| Ask a question or share how you use it | [Discussions](https://github.com/kitshelf/scamcheck/discussions) |
| Report a bug in the workflow or a rubric | [Issues](https://github.com/kitshelf/scamcheck/issues) |

## What support is not

ScamCheck does not screen messages for you through this repo, does not recover money, and does not give legal or financial advice. If you have already paid or sent an ID, the recovery branch in [`shared/recovery.md`](shared/recovery.md) names the channels; the report channels are the FTC (`reportfraud.ftc.gov`) and IC3 (`ic3.gov`).

**Never paste a real message containing your own personal data** into an issue or discussion. Redact first: replace your name, phone, address, and account digits with `[NAME]`, `[PHONE]`, `[ADDRESS]`, `[ACCOUNT]`.
