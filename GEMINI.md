# GEMINI.md

This repository is ScamCheck. This file is a pointer, not the instruction set. Gemini CLI auto-loads it, so it stays thin on purpose. The rules are written once, in their owning files; they are never copied here.

1. Read [`WHAT-THIS-IS.md`](WHAT-THIS-IS.md), the charter. It governs everything.
2. Read [`AGENTS.md`](AGENTS.md), your entry point, and follow it.
3. Screening a message → [`screen/AGENTS.md`](screen/AGENTS.md) plus `screen/00-principles.md` and `screen/01-screen/screen.md`.
4. Never fetch, click, or transmit anything. Never commit anything from any `my-files/` directory.
